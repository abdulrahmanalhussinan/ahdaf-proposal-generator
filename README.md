# مولّد العروض الفنية — أهداف للخدمات التسويقية
**Ahdaf Proposal Generator**

نظام داخلي يكتب عرضًا فنيًا كاملًا بهوية أهداف انطلاقًا من معلومات المشروع. بعد الكتابة يراجع الفريق العرض ويعدّله، ثم يصدّره ملف PDF أو PowerPoint جاهزًا للإرسال إلى العميل.

---

## التشغيل

**على Windows:** انقر مرتين على `start.bat`. في أول تشغيل يثبّت المتطلبات، ثم يفتح النظام في المتصفح على `http://127.0.0.1:8765`.

**يدويًا:**
```bash
pip install -r requirements.txt
python -m app
```

المتطلبات: Python 3.10 أو أحدث، ومتصفح Microsoft Edge (يأتي مع Windows) لإنشاء ملفات PDF. في الأجهزة التي لا تحتوي Edge نفّذ `python -m playwright install chromium`.

البيانات تُحفظ في مجلد `data/` (قاعدة البيانات والصور المرفوعة). انسخ هذا المجلد احتياطيًا بشكل دوري.

## مسار العمل

1. **التصميم والحجم:** أربعة تصاميم بتخطيطات مختلفة: «أهداف الكلاسيكي» (تموجات أهداف، والعناوين من اليمين)، و«الليلي الفاخر» (داكن بدوائر ولمسات ذهبية، والعناوين في المنتصف)، و«العصري الجريء» (أشكال هندسية، من اليمين)، و«الأبيض الأنيق» (إضاءات ليلكية وخطوط ناعمة، في المنتصف). واختر **عدد الصفحات** (10، 15، 20، 25، 30 أو أي عدد): يحدد النظام مستوى التفصيل وحجم كل قسم ليقترب منه، ويعرض المحرر العدد الفعلي مع زر «ملاءمة» إن زاد.
2. **المشروع:** اسم العميل والقطاع و**نشاط العميل** بكلامك، واسم المشروع ونوعه، ثم إما **فكرة مختصرة** يبني عليها الذكاء الاصطناعي، أو **طلبك بالتفصيل**: يلتزم به العرض حرفيًا (الأقسام والأفكار والأعداد والأماكن)، ويكمل الباقي، ويضيف أي قسم تطلبه غير موجود. والملف التعريفي للعميل اختياري.
3. **اقتراحاتك (اختيارية):** الجمهور، والأهداف، والمنصات، والخدمات، والمدة، والأسلوب، والمشاهير، والأقسام الإضافية. كل قائمة فيها خيار **«أخرى»**.
4. **التوليد:** يقترح النظام **الفكرة الإبداعية** والرسالة الأساسية ومقترحات الشعار، و**أفكارًا تفعيلية**، و**محاور المحتوى** مع نموذج أسبوع نشر، والجمهور والأهداف والخدمات والمنهجية والجدول الزمني والفريق والمؤشرات.
5. **المحرر:** تعديل كل النصوص والجداول والكميات والجدول الزمني والفريق والمؤشرات والصور، وإعادة ترتيب الأقسام، و«إعادة توليد القسم» بنفس الأسلوب أو بأسلوب آخر مع التراجع. يُحفظ كل تعديل تلقائيًا.
6. **التصدير:** PDF بالتصميم المختار، أو PowerPoint قابل للتعديل.

### أقسام العرض
الغلاف، محتويات العرض، عن أهداف (اختياري)، المقدمة، فهمنا للمشروع، أهداف المشروع، الفكرة الإبداعية، أفكار تفعيلية مقترحة، محاور المحتوى وخطة النشر (لمشاريع المحتوى والمنصات)، نطاق العمل، منهجية وآلية التنفيذ، المخرجات، الجدول الزمني، فريق العمل، مؤشرات الأداء، الحوكمة وإدارة المشروع، الافتراضات والمتطلبات، المخاطر وآلية التعامل معها، الإطار المالي (اختياري)، أعمال ذات صلة (اختياري)، الخاتمة، ثم صفحة «شكرًا لكم».

### يقترح الأفكار، ولا يخترع الحقائق
- النظام **يقترح من عنده**: الفكرة، والأفكار التفعيلية، والجمهور، والأهداف، والخدمات، والمدة. وكل ذلك قابل للتعديل، ويُعرض في المحرر ما اقترحه النظام بنفسه لتراجعه.
- لا يضع أرقامًا عن نتائج أو أحجام جمهور أو ميزانيات أو جوائز من عنده. القيم المستهدفة لمؤشرات الأداء تأتي من الأرقام التي تكتبها، وبدونها يُكتب «يُحدد مع العميل».
- الاختبار `test_no_invented_numbers` يتحقق من ذلك لكل أنواع المشاريع.

## الكتابة بـ Claude
إذا كان **Claude Code** مثبتًا على الجهاز ومسجّل الدخول، يكتب Claude العرض كاملًا تلقائيًا دون أي إعداد. ويمكن بدلًا من ذلك وضع مفتاح API في ملف `.env`، ويُستخدم المفتاح إن وُجد:
```
ANTHROPIC_API_KEY=sk-ant-...
```
- Claude يقرأ المشروع، و**فكرتك وتوجيهك** (يبني عليها ولا ينسخها)، و**الملف التعريفي للعميل** إن رفعته، و**قائمة المشاهير**، ثم يكتب كل الأقسام: الفهم، والأهداف، والفكرة، والتفعيلات، والمشاهير المرشحين، والمحتوى، ونطاق العمل، والمراحل، والمخرجات، والمؤشرات، والخاتمة. الجدول الزمني يُبنى من المراحل التي يقترحها.
- الكتابة على مرحلتين: الفكرة والتفعيلات أولًا، ثم باقي الأقسام بالتوازي. تستغرق عادة من 3 إلى 6 دقائق، وتُحسب من حدود استخدام حساب Claude.
- **الحقائق محمية:** لا يُذكر أي مشهور من خارج قائمتك، وأرقام المتابعين تُنقل من الشيت لا من النموذج. وأي جملة فيها نسبة أو رقم كبير غير موجود في مدخلاتك أو الملف التعريفي أو الشيت تُحذف تلقائيًا.
- إن تعذر الوصول إلى Claude (انقطاع أو انتهاء حد الاستخدام) يُكتب العرض بالمحرك الداخلي وتظهر رسالة بذلك.
- `AI_PROVIDER=rules` في `.env` يوقف الكتابة بـ Claude. التعليمات في `app/ai/prompts/`.

## المشاهير والملف التعريفي
- **صفحة «المشاهير»:** ارفع شيت Excel أو CSV. يتعرف النظام على الأعمدة تلقائيًا (الاسم، الحساب، المنصة، المتابعين، المجال، المدينة…)، ويقبل عمودًا لكل منصة وأكثر من ورقة. الأسماء المكررة لا تُضاف مرتين.
- في المعالج: «المشاهير: تلقائي» يرشّح من القائمة إذا كانت الفكرة أو نوع المشروع يحتاج مشاهير، ويقدّم من يناسب المدينة والقطاع.
- **الملف التعريفي للعميل** (PDF أو Word أو PowerPoint) يُرفع من الخطوة الثانية، ويقرأ Claude نصه ليفهم العميل.
- أقسام فريق العمل والحوكمة والافتراضات والمخاطر غير مضافة افتراضيًا، وتُضاف من «أقسام إضافية» عند الحاجة.

## البنية التقنية

```
app/
  main.py               نقطة التشغيل (FastAPI) + الملفات الثابتة + ترويسات الأمان
  config.py             الإعدادات من البيئة / .env
  api/                  واجهات REST (العروض، المكتبة، العملاء، القوالب، الإعدادات، الرفع)
  services/proposals.py منطق العمل: إنشاء، تعديل، إعادة توليد، نسخ، نسخ محفوظة، قوالب
  generator/            محرك كتابة العروض
    analyzer.py         تحليل المدخلات: النوع، القطاع، المنصات، الأهداف، المدة، والنواقص
    engine.py           بناء كل قسم + إعادة توليد قسم واحد
    phrases.py          صياغات حسب الأسلوب (رسمي، Corporate، فاخر، تسويقي، مختصر، تفصيلي)
    knowledge/          المعرفة الأولية: أنواع المشاريع، القطاعات، الخدمات، الأدوار، المؤشرات، المنصات
  ai/                   طبقة Claude الاختيارية + prompts/
  exporters/            PDF (Playwright + Edge) و PowerPoint (python-pptx)
  data/                 SQLite + طبقة Repository (كل SQL في مكان واحد) + البيانات الأولية
  core/                 أدوات اللغة العربية، المخططات، الأمان (نقطة ربط تسجيل الدخول ورموز الطباعة)
web/
  index.html            التطبيق (Preact + htm بدون أدوات بناء)
  print.html            صفحة الطباعة التي يُنشأ منها PDF
  js/document/          محرك تخطيط صفحات العرض، مشترك بين المعاينة والـ PDF
  js/views/             الصفحات: الرئيسية، المعالج، المحرر، العروض، القوالب، العملاء، المكتبة، الإعدادات
  css/                  هوية الواجهة + هوية مستند العرض
tests/                  اختبارات المحرك والواجهات البرمجية + اختبار شامل بالمتصفح (e2e_test.py)
```

### نقاط التوسعة
- **تسجيل الدخول:** كل المسارات تعتمد على `get_current_user` في `app/core/security.py`. يكفي ربط هذه الدالة بنظام الهوية، دون تعديل المسارات.
- **قاعدة بيانات أخرى (PostgreSQL مثلًا):** كل استعلامات SQL موجودة في `app/data/repositories.py`.
- **مزوّد ذكاء اصطناعي آخر:** كل الكتابة في `app/ai/author.py`: `build_request` يبني الطلب، و`call` يرسله، و`apply` يطبق الرد مع الحماية.
- **أنواع مشاريع أو قطاعات جديدة:** تُضاف من المكتبة، أو في `app/generator/knowledge/`.

### الأمان
- الأسرار (المفاتيح) تُحفظ في `.env` على الخادم فقط، والإعدادات التي يمكن تعديلها من المتصفح محددة في قائمة مسموحة.
- صفحة طباعة الـ PDF تعمل برمز صالح لمرة واحدة ولعرض واحد لمدة دقيقتين.
- الرفع يقبل الصور فقط بحجم أقصى 8MB، ويرفض ملفات SVG التي تحتوي شيفرة. أسماء الملفات تُولَّد عشوائيًا.
- كل النصوص تُعرض بعد تهريبها (escaping) لمنع حقن الشيفرة، وترويسات أمان على كل الاستجابات.
- الخادم يستمع على `127.0.0.1` افتراضيًا. لتشغيله على شبكة الشركة غيّر `AHDAF_HOST` بعد إضافة تسجيل الدخول.

## نسخة الموقع (GitHub Pages)
`python scripts/publish_pages.py` يبني نسخة تعمل كاملة داخل المتصفح (Pyodide) وينشرها على https://abdulrahmanalhussinan.github.io/ahdaf-proposal-generator/ .
- **الكتابة بـ Claude في الموقع:** من «الإعدادات» يضع كل مستخدم مفتاح Claude API الخاص به (من console.anthropic.com). يُحفظ المفتاح في متصفحه فقط، ويُرسل مباشرة إلى Claude ولا يمر بأي خادم، ثم يكتب Claude العرض بنفس طريقة نسخة الجهاز ونفس الحماية. بدون مفتاح يكتب المحرك الداخلي.
- العروض وقائمة المشاهير تُحفظ في متصفح كل مستخدم. تصدير PDF من نافذة الطباعة، وPowerPoint من نسخة الجهاز.
